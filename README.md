# 🎂 Verificador de Idade e Maioridade

Um plicativo interativo de console desenvolvido em **C# / .NET** que calcula a idade do usuário com base no ano de referência atual (2026) e determina se ele já atingiu a maioridade legal.

---

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** C#
* **Plataforma:** .NET (Console Application)
* **Controle de Versão:** Git & GitHub

---

## ⚙️ Funcionalidades

* Recebe os dados de nascimento fornecidos pelo usuário via console.
* Calcula a idade exata com base no ano de referência (2026).
* Valida e exibe se o usuário é **maior de idade** (18 anos ou mais) ou **menor de idade**.
* Exibe mensagens interativas com tratamento de fluxo condicional.
